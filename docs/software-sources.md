# Project Helios Software Sources

## Debian 13

Used for:

- Xorg
- Openbox
- LightDM
- Intel VA-API support
- PipeWire audio
- NetworkManager
- PCManFM
- MPV
- SMB support
- Flatpak
- System utilities

## Flathub

Used for:

- Moonlight
- Plex HTPC
- FreeTube
- Spotify

## Official External Sources

### Brave Browser

Installed from Brave's official Debian repository.

### Flex Launcher

Installed from the official Flex Launcher GitHub release.

## Excluded Applications

- Kodi
- Firefox
- Google Chrome

Brave will be the general-purpose browser.
FreeTube will be the dedicated YouTube application.
