# Project Helios Configuration

The main configuration file is:

    config/helios.conf

## Default display

- Resolution: 1920 x 1080
- Refresh rate: 60 Hz

## Default user

The finished media box will use:

    helios

This account is separate from the development computer's `pyrus` account.

## Network media

The SMB server and share fields are intentionally blank.

They will be configured after the basic system is working.

## Fullscreen applications

The following applications will launch fullscreen where supported:

- Moonlight
- Plex HTPC
- FreeTube
- Brave
- MPV

Spotify will launch maximized because its Linux client does not provide a reliable dedicated fullscreen mode.
